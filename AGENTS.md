# AGENTS.md — правила проекта

## Что это
Одностраничный сайт: фото/аватар человека и мини-игра «крестики-нолики» против компьютера.

## Структура
- `index.html` — разметка страницы.
- `style.css` — оформление (тёмная тема, адаптив).
- `script.js` — логика игры (игрок X, компьютер O, счёт).
- `assets/avatar.svg` — аватар-заглушка (можно заменить на фото).

## Как смотреть локально
```
py -m http.server 8123
```
Открыть http://localhost:8123/

## Как менять
- Аватар: положить фото в `assets/` и поменять `src` у `<img class="avatar">`.
- Имя, текст: `index.html`.
- Цвета: переменные `--*` в начале `style.css`.
- Сложность ИИ: функцию `pickBestMove` в `script.js`.

## Публикация
GitHub Pages из ветки `main`, корень репозитория.
