# AGENTS.md — правила проекта

## Что это
Одностраничный сайт: большое фото, цитата, аудиоплеер и мини-игра «крестики-нолики» против компьютера.

## Структура
- `index.html` — разметка страницы.
- `style.css` — оформление (тёмная тема, адаптив, плеер).
- `script.js` — логика игры (игрок X, компьютер O, счёт).
- `player.js` — логика плеера (play/pause, перемотка, громкость, повтор, автозапуск с первого нажатия).
- `assets/avatar.jpg` — фото пользователя.
- `assets/music.mp3` — музыка «Halal Beats — Where you are (Slowed)».

## Как смотреть локально
```
py -m http.server 8123
```
Открыть http://localhost:8123/

## Как менять
- Фото: заменить `assets/avatar.jpg`.
- Музыку: заменить `assets/music.mp3` (название в плеере — в `index.html`, `.track-title` / `.track-artist`).
- Текст цитаты: `index.html`.
- Цвета: переменные `--*` в начале `style.css`.
- Сложность ИИ: функция `pickBestMove` в `script.js`.

## Важно
Браузеры запрещают автоматический звук до первого действия пользователя.
Плеер запускается при первом нажатии/тапе по странице либо кнопкой ▶.
